# BabelBar 3.0.2

- Диктовка распознаёт речь на устройстве, когда в системе есть модель языка: без сетевых задержек, слова появляются быстрее. Серверное распознавание остаётся запасным вариантом, если не включён режим «только на устройстве».
- Диктовка стабильнее запускается в браузерах и Electron-редакторах: приложение запрашивает у них дерево доступности и ждёт, пока оно появится, вместо отказа с первой попытки.
- Медленные редакторы получают до 0,6 с на подтверждение правки, прежде чем сессия прекращается.
- Исправлен сбой соответствия между Fn и диктовкой: нажатие Fn во время активной сессии теперь останавливает её и не сдвигает следующий запуск на шаг.

Проверки: Release на Xcode 16.4, 26 регрессионных проверок. Живая проверка микрофона и сторонних приложений не выполнена.
