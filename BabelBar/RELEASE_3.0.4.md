# BabelBar 3.0.4

- Потоковая диктовка вставляет текст фразами: в поле попадает только устойчивая часть речи, без правок и замен уже написанного. Последние два слова ждут, пока распознаватель их подтвердит, поэтому вставка идёт с отставанием на пару слов, а не с задержкой до конца фразы.
- Пауза в речи в 0,8 с сразу вставляет всё оставшееся; остановка диктовки тоже дописывает хвост.
- Вставка стала «только дописывать»: реже обращения к целевому приложению, меньше шансов, что чужое поле помешает сессии.

Проверки: Release на Xcode 16.4, 46 регрессионных проверок. Живая проверка микрофона и сторонних приложений не выполнена.
