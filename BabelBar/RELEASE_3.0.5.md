# BabelBar 3.0.5

- Ускорены запуск приложения и включение микрофона по Fn: аудиодвижок готовится заранее и используется повторно, пока не изменится устройство. Подготовка, запуск и остановка микрофона больше не блокируют интерфейс.
- В режиме «После фразы» убрана дополнительная пауза перед записью по Fn. Сочетание Shift+Fn по-прежнему позволяет надиктовать текст с переводом.
- Ускорена загрузка локального Whisper: установленная модель открывается с диска, без повторного поиска через загрузчик. Одновременные запросы используют одну загрузку модели.
- Добавлен потоковый режим с локальным WhisperKit. Распознанные фрагменты вставляются во время речи, а остановка дописывает оставшийся текст.
- Настраиваемые голосовые сочетания работают с выбранным режимом диктовки. Сочетания можно изменить или очистить; перевод голосом назначается отдельно.
- Улучшены вставка текста, пробелы после пунктуации и обработка смены фокуса. Поиск поля ввода выполняется в фоне, а анимация записи останавливается после скрытия индикатора.

Проверки: подписанная Release-сборка, 74 регрессионные проверки. Быстрый запуск прослушивания и вставка текста подтверждены пользователем на установленной сборке с этими изменениями.
