# Оформление окна установки (DMG)

Пользователь открывает `BabelBar-<версия>.dmg` и видит окно 660×420: слева иконка
приложения, справа папка `Applications`, между ними надпись «drag and drop» и стрелка.

| Файл | Что делает |
|---|---|
| `make_background.swift` | рисует фон окна (CoreGraphics, без внешних зависимостей) |
| `background.png`, `background@2x.png`, `background.tiff` | результат отрисовки; `.tiff` содержит обе плотности и кладётся в том |
| `dmg_build.sh` | собирает образ: том, фон, раскладка через Finder, сжатие в UDZO |

## Как это работает

Иконки на фоне **не нарисованы** — это настоящие иконки Finder. Фон задаёт только
подложку, а положение иконок пишется в `.DS_Store` тома через AppleScript. Поэтому
центры иконок в двух местах должны совпадать:

- `make_background.swift` → `appIconCenter` / `dstIconCenter`;
- `dmg_build.sh` → `set position of item … to {165, 170}` / `{495, 170}`.

Размер окна (660×420) равен размеру картинки: `W`/`H` в свифте и `bounds` в скрипте.

## Правки

Поменял фон или размеры — просто запусти сборку DMG: `dmg_build.sh` сам перерисует
картинку, если `make_background.swift` новее `background.tiff`. Отдельно посмотреть
результат:

```bash
swift make_background.swift . && open background.png
```

## Тонкости, на которых легко обжечься

- **Боковая панель Finder входит в `bounds`.** Пока она видна, окно получается шире
  фона и картинка съезжает. В скрипте сначала `set sidebar width … to 0`, потом размер.
- **Образ собирается как UDRW с запасом 40 МБ.** В том впритык Finder не может дописать
  `.DS_Store`, и раскладка теряется.
- **Нужен доступ «Автоматизация → Finder»** (система спросит один раз). Без него DMG
  соберётся, но без фона и раскладки — скрипт напечатает предупреждение.
